ABOUT THIS VIEW

目前是事件時間軸，不是假裝精準的節奏譜。

Basic Pitch TAB JSON 提供 onset、offset 與最佳化 string / fret；目前仍沒有完整拍號、tempo map、節奏量化與連音記號。 因此這個播放器依真實秒數排列事件；之後加入 beat tracking，才適合重建正式小節。
