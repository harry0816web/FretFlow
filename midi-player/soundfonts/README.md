# Sound bank used for the local demo comparison

`GeneralUserGSv1.471.sf2` is GeneralUser GS 1.471 by S. Christian Collins,
downloaded from the same asset URL used by Spotify's Basic Pitch demo:

https://basicpitch.spotify.com/soundfont/GeneralUserGS1.471/GeneralUserGSv1.471.sf2

Author's project: https://www.schristiancollins.com/generaluser.php

The binary is a local, ignored dependency and is not committed or repackaged.
Consult the author's distribution and license before redistributing it. If it
is absent, the player falls back to macOS's built-in DLS bank. From this folder,
it can be downloaded again with:

```sh
curl --fail --location --output GeneralUserGSv1.471.sf2 \
  https://basicpitch.spotify.com/soundfont/GeneralUserGS1.471/GeneralUserGSv1.471.sf2
```
